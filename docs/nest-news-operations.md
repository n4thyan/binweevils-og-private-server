# Nest News operations

Nest News in Flash and the website Bin Bulletin both read `bwps.news_articles`.
The Flash-compatible XML is generated by `/nestNews/feed.php` and served at the original URL `/nestNews/xml/uk/nestNews.xml` through `.htaccess`.

## Add an article

```sql
USE bwps;
INSERT INTO news_articles
  (title, body, category, image_path, author, published_at, expires_at,
   is_published, is_top_story, created_at, updated_at)
VALUES
  ('HEADLINE', 'Article body. Flash-compatible <a href="event:1">links</a> are allowed.',
   1, NULL, 'Bin Weevils Team', UNIX_TIMESTAMP(), NULL,
   1, 0, UNIX_TIMESTAMP(), UNIX_TIMESTAMP());
```

Categories follow the original SWF: `1=news`, `2=special area`, `3=tycoon`, `4=hunt`, `5=competition`.
Only one current article should normally have `is_top_story=1`.

## Add an optional link

Use the inserted article ID:

```sql
INSERT INTO news_article_links
  (article_id, display_order, link_target, link_type, tracking_id)
VALUES
  (LAST_INSERT_ID(), 1, '/game.php', 1, 'launch-news');
```

Original link types are `1=web address`, `2=location ID`, `3=external UI`.

## Edit or unpublish

```sql
UPDATE news_articles
SET title='UPDATED HEADLINE', body='Updated body', updated_at=UNIX_TIMESTAMP()
WHERE id=1;

UPDATE news_articles
SET is_published=0, updated_at=UNIX_TIMESTAMP()
WHERE id=1;
```

No SWF rebuild or separate website edit is needed. Verify both:

- `http://localhost/nestNews/xml/uk/nestNews.xml`
- `http://localhost/`
