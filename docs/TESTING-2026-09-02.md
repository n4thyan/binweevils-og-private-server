## Failures / blockers

### FAIL — authenticated WebSocket 2087 cannot process normal `ws` message objects

An authenticated Play-page connection reaches `CONNECTION ESTABLISHED`, but the first normal message/ping produces:

```text
TypeError: dataStr.split is not a function
    at BinWeevilsWeb.handleData (...\server\BinWeevilsWeb.js:97:28)
    at WebSocket.<anonymous> (...\server\BinWeevilsWeb.js:227:30)
```

The current `ws` library passes a `Buffer` to the message handler while `handleData()` assumes a string. This disconnects the authenticated 2087 client. It did not crash the 9339/2087 listeners. **No fix was made** because this is server/protocol code, explicitly outside the allowed AFK fix scope.

### BLOCKED — real Flash gameplay, selector pixels, Nest and fullscreen gesture

- Headless Chromium has no Flash plugin and correctly displays “Adobe Flash Player is no longer supported.”
- The real repository Electron client launched, but its existing window was minimized/logged out; it was not driven or given credentials while the owner was AFK.
- Therefore server-selector pixels, selecting Mulch, entering the game/Nest, original HUD/map/shop controls, fullscreen entry and Escape exit remain a manual Electron/PepperFlash test.
- The server-selection PHP contract itself passed and exposed `Mulch` at `127.0.0.1`.
